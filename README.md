# Django Basic Backend

This is a basic Django backend project I made while learning Django.

The project is mainly for understanding how a Django backend works and how requests are handled.

## Concepts Used

* Django project and app structure
* URL routing
* Views
* HTTP responses
* JSON responses
* Redirects
* HTML templates
* Request and response flow

## About the Project

The project contains a few simple endpoints such as:

* Home page
* About page
* Users JSON response
* Products JSON response
* Contact response
* Redirect from one URL to another
* HTML page using Django templates

I created this project to get familiar with the basic structure and working of Django before moving on to more advanced backend development.
